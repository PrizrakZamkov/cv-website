# Сайт-резюме

Станислав Делюков, Unity и Frontend разработчик.

Открыть: https://prizrakzamkov.github.io/cv-website/

Написан без фреймворков и сборки: HTML, CSS и JavaScript. Русский и английский, анимации на CSS, при включённом «уменьшении движения» в системе анимации отключаются. Пиксельный аватар рисуется кодом из массива строк в `main.js`.

## Как устроено

- `data.js` — весь текст сайта и список проектов. Чтобы что-то поменять на странице, достаточно этого файла.
- `main.js` — отрисовка, переключение языка, окно проекта, интро.
- `style.css` — оформление.
- `cv-gamedev.html`, `cv-frontend.html` — резюме под два направления. PDF из них получается через печать в браузере.

Если в `data.js` окажется ошибка, страница не останется пустой: интро уберётся, а имя и контакты всё равно будут видны.

## Как обновлять

- Новый проект: скопировать любой блок в `projects` и поменять поля. `featured: true` делает карточку большой, `status: 'done'` поднимает её выше. Карточек лучше держать чётное число, иначе последний ряд будет неполным.
- Картинка или видео к проекту: положить файл в папку `img` и добавить `image: 'img/name.gif'` или `video: 'img/name.mp4'`.
- Ссылки проекта: `links: [{ label: 'GitHub', href: 'https://...' }]`.
- Резюме: открыть `cv-*.html`, поправить текст, Ctrl+P, «Сохранить как PDF» поверх нужного `Delyukov-CV-*.pdf`. Телефон в них лежит закомментированной строкой, потому что файлы публичные.
- Картинка для превью ссылки в мессенджерах — `preview.png`, адрес сайта для неё прописан в `index.html` в блоке `og:`.
